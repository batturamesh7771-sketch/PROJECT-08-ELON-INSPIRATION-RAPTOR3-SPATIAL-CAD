# Contributing to Project 08: SpaceX Starship Raptor 3 Spatial CAD

We welcome contributions, bug fixes, performance improvements, and new spatial gesture algorithms!

## Guidelines
1. **Fork & Branch**: Create a feature branch (`git checkout -b feature/new-gesture`).
2. **Code Style**:
   - Keep JavaScript vanilla and modular.
   - Retain responsive Tailwind utility classes.
   - Follow Three.js best practices (dispose unused geometries/materials).
3. **Verification**:
   - Run `node scripts/verify_app.js` to ensure zero runtime or console exceptions.
4. **Pull Requests**:
   - Submit PR with clear before/after descriptions.
