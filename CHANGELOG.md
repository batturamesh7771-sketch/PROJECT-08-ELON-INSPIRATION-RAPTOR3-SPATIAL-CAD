# Changelog

All notable changes to **Project 08: SpaceX Starship Raptor 3 Spatial CAD** will be documented in this file.

## [1.0.0] - 2026-10-10
### Added
- **10,888 Parts Procedural Architecture**: Complete Starship Raptor 3 (V3) engine hierarchy including Inconel 718 bell nozzle, GRCop-42 cooling jacket, swirl injectors, dual turbopumps, A286 fasteners, internal manifold lattices, and TVC gimbal actuators.
- **MediaPipe AI Hand Tracking**: Real-time 21-node skeletal tracking at 60 FPS with Euclidean distance finger classification.
- **High-Contrast Light Theme**: Tuned for zero-washout mobile video recording with crisp off-white background (`#F4F5F7`), dual-tone blueprint CAD grid, and rich navy typography (`#0F172A`).
- **14+ Spatial Gestures**: Air-Pinch & Drag subassembly extraction, Snap pre-burner ignition, Palm Thrust throttle test, Both Fists assemble/explode toggle, Double Swipe Out Zen mode, and more.
- **Supersonic Plume & Combustion Physics**: 1,400-particle supersonic exhaust plume with 4 dynamic Mach diamond shock cones and thermal CFD emissive heatmaps.
- **Procedural Audio Synthesizer**: Web Audio API real-time combustion rumble and spark crackles with dynamic gain modulation.
- **Automated Testing Suite**: Headless Chrome DevTools Protocol verification scripts (`scripts/verify_app.js` and `scripts/capture_demo.js`).
- **GitHub Actions Automation**: Automated GitHub Pages deployment pipeline (`.github/workflows/deploy.yml`).
